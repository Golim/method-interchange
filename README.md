# When POST Becomes GET: Investigating HTTP Method Interchangeability and Its Security Implications

This repository contains the code for the paper "*When POST Becomes GET: Investigating HTTP Method Interchangeability and Its Security Implications*", submitted for review to ACSAC 2026.

## Repository Contents

### `mide/`

This directory contains the implementation of the Method Interchangeability Detection Engine (MIDE) tool.

Refer to the [README.md](./mide/README.md) for setup and usage instructions.

### `analysis/`

This directory contains scripts for analyzing the outputs of MIDE and generating the tables and figures presented in the paper.

Refer to the [README.md](./analysis/README.md) for instructions on running the analysis scripts and interpreting their outputs.
